================================================================================
           HOSTELCODE — STEP-BY-STEP PRODUCTION DEPLOYMENT GUIDE
================================================================================

This guide provides the exact steps to publish HostelCode live to the internet.

--------------------------------------------------------------------------------
0. TROUBLESHOOTING & DEPLOYMENT SAFETY MEASURES
--------------------------------------------------------------------------------
1. DATABASE RETENTION & PERSISTENCE (SAFE DEPLOYS):
   - Problem: Redeploying updates was resetting the SQLite database because
     `hostelcode.db` was committed into Git and container restarts wiped it.
   - Solution Implemented:
     a) `hostelcode.db` is now UNTRACKED from Git and added to `.gitignore`.
        Pushing updates (`git push`) will NEVER overwrite your live database!
     b) Dual Persistent Storage Path Support:
        The server supports `DATA_DIR` and `DATABASE_PATH` environment variables.
        If using a persistent disk (Render, Docker, VPS), mount to `/var/data`
        and set `DATA_DIR=/var/data`.
     c) Client-Side Self-Healing Auto-Restore:
        Even on free-tier hosting (ephemeral container filesystem restarts),
        the browser client automatically detects missing rooms on 404, re-syncs
        the room and all files to the server, and prevents any room loss.

2. RENDER BACKEND BUILD:
   - Configured `render.yaml` with `--include=dev` and Node dependencies.

3. VERCEL FRONTEND BUILD:
   - Updated `apps/web/package.json` build command to:
     `tsc -b ../../packages/shared && tsc -b && vite build`
     so that Vercel automatically compiles the shared package before building
     the web client.

================================================================================
STEP 1: PUSH THE UPDATED FIXES TO GITHUB
================================================================================
Open your terminal in the project directory (`Code Fusion`) and run:

  git add .
  git commit -m "fix: database persistence and auto-restore across deployments"
  git push origin main

Once pushed to GitHub, both Render and Vercel will automatically redeploy. Your existing
rooms and data will stay completely safe and intact!

================================================================================
STEP 2: DEPLOY THE COLLABORATION BACKEND ON RENDER (FREE)
================================================================================
The collaboration backend runs Node.js, WebSockets (for Yjs CRDT real-time sync),
and the SQLite database for secure rooms and files.

1. Go to https://render.com and sign in.

2. In the Render Dashboard, click the blue "New +" button and choose "Web Service".

3. Connect your GitHub repository (`Code-Fusion`).

4. Configure the Web Service settings:
   - Name: hostelcode-server
   - Region: Singapore / Frankfurt / Oregon (choose closest to you)
   - Branch: main
   - Root Directory: (Leave completely empty)
   - Runtime: Node
   - Build Command:
       npm install --include=dev && npm run build:shared && npm run build:server
   - Start Command:
       node apps/server/dist/index.js
   - Instance Type: Free

5. Add Environment Variables (in the "Environment Variables" section):
   -------------------------------------------------------------------------
   KEY              VALUE
   -------------------------------------------------------------------------
   PORT             10000
   HOST             0.0.0.0
   NODE_ENV         production
   CORS_ORIGIN      *
   -------------------------------------------------------------------------

6. Click "Deploy Web Service".

7. Once deployed, Render will show "Your service is live 🎉" and give you a URL:
   Example: https://hostelcode-server.onrender.com

8. Verify your server is live:
   Open https://hostelcode-server.onrender.com/health in your browser.
   It should return:
   {
     "status": "ok",
     "service": "HostelCode Collaboration Server",
     "version": "0.1.0"
   }

   *** SAVE YOUR RENDER ENDPOINTS ***
   - HTTP URL: https://hostelcode-server.onrender.com
   - WSS URL:  wss://hostelcode-server.onrender.com  (Notice wss:// instead of https://)

================================================================================
STEP 3: DEPLOY THE WEB FRONTEND ON VERCEL (FREE)
================================================================================
The frontend is the React + Vite + Monaco Editor client with local storage caching.

1. Go to https://vercel.com and sign in with GitHub.

2. Click "Add New..." -> "Project".

3. Find your `Code-Fusion` repository and click "Import".

4. Configure the Project:
   - Framework Preset: Vite
   - Root Directory: apps/web   (Or leave as root `.`)
   - Build Command: npm run build
   - Output Directory: dist

5. Add Environment Variables (IMPORTANT):
   Add the following two environment variables:

   -------------------------------------------------------------------------
   KEY                      VALUE
   -------------------------------------------------------------------------
   VITE_COLLAB_SERVER_URL   wss://hostelcode-server.onrender.com
   VITE_SERVER_HTTP_URL     https://hostelcode-server.onrender.com
   -------------------------------------------------------------------------
   (Replace `hostelcode-server.onrender.com` with YOUR real Render backend URL!)

6. Click "Deploy".
   Vercel will now execute:
   `tsc -b ../../packages/shared && tsc -b && vite build`
   and deploy successfully without any missing module errors!

   Your live URL will be ready:
   https://hostelcode.vercel.app (or custom domain)

================================================================================
STEP 4: TESTING YOUR LIVE COLLABORATION ACROSS MULTIPLE DEVICES
================================================================================
Once both frontend and backend are live:

1. Device A (Your Laptop):
   - Open your live Vercel URL (e.g., https://hostelcode.vercel.app).
   - Register or sign in with your email and password.
   - Click "Create Team".
   - You will see a unique 6-digit code (e.g. "K9X2B7").
   - Click "Launch Workspace".
   - Click "Upload Files" or "+ Create File" to add files to the room.

2. Device B (Teammate's Laptop or Phone):
   - Open https://hostelcode.vercel.app on another device.
   - Register or sign in.
   - Click "Join Team".
   - Enter the 6-digit code "K9X2B7" (or click the invite link).
   - Click "Join Room".

3. Observe Real-Time Collaboration:
   - Device B immediately sees all files uploaded by Device A from the secure database!
   - Both users appear in the "Team Members" list with 🟢 Active status.
   - When Device A moves their cursor to Line 3, Device B sees a colored cursor
     pointer on Line 3 with Device A's name hovering above it!
   - Edits made by any user sync in real-time with zero conflicts via Yjs CRDT.
   - Clicking "Undo" (or pressing Ctrl+Z) undos ONLY the active user's changes!
